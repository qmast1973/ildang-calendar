# ildang-c# 
🗓️ 일당달력 (Daily Wage Calendar)

건설 현장, 인테리어, 물류 등 일당직 및 프리랜서 근무자를 위한 간편한 모바일 친화적 공수/정산 관리 웹앱(PWA)입니다. 복잡한 서버나 데이터베이스 없이 단일 HTML 파일만으로 완벽하게 동작하며, 모든 데이터는 사용자의 기기에 안전하게 저장됩니다[span_0](start_span)[span_0](end_span).

## ✨ 주요 기능

*   **한눈에 보는 직관적인 달력 UI**
    *   스와이프 제스처를 통한 부드러운 월 이동 지원[span_1](start_span)[span_1](end_span).
    *   달력 위에서 날짜별 출근 현장과 공수(0.5, 1.0 등)를 즉각적으로 확인[span_2](start_span)[span_2](end_span).
*   **스마트한 실급여 및 정산 계산**
    *   3.3% 사업소득세 공제 기능 지원[span_3](start_span)[span_3](end_span).
    *   식대, 유류비 등 기타 경비를 합산하여 정확한 최종 실수령액 파악 가능[span_4](start_span)[span_4](end_span).
*   **빠른 입력 및 업체 관리**
    *   자주 가는 현장을 프리셋으로 저장하여 터치 한 번으로 빠른 일당 기록[span_5](start_span)[span_5](end_span).
    *   '휴무(0공수)' 버튼을 통한 간편한 휴일 등록[span_6](start_span)[span_6](end_span).
*   **월별 정산 및 미수금 관리**
    *   월별/업체별 누적 공수 및 최종 수령액 합계 조회[span_7](start_span)[span_7](end_span).
    *   특정 업체의 한 달 치 일당을 '전체 입금 완료' 또는 '미지급' 상태로 일괄 변경[span_8](start_span)[span_8](end_span).
*   **데이터 공유 및 백업**
    *   정산 내역을 텍스트로 변환하여 카카오톡이나 문자 메시지로 바로 공유[span_9](start_span)[span_9](end_span).
    *   엑셀 작업용 CSV 파일 내보내기 지원[span_10](start_span)[span_10](end_span).
    *   기기 변경 시에도 기록을 유지할 수 있는 JSON 파일 백업 및 불러오기[span_11](start_span)[span_11](end_span).

## 🚀 설치 및 사용 방법

본 애플리케이션은 PWA(Progressive Web App)를 지원합니다[span_12](start_span)[span_12](end_span).

1.  스마트폰의 웹 브라우저(크롬, 사파리, 삼성 인터넷 등)를 통해 호스팅된 웹 주소로 접속합니다.
2.  화면 하단의 **`📱 홈 화면에 일당달력 설치`** 버튼을 누르거나, 브라우저 메뉴에서 **`홈 화면에 추가`**를 선택합니다[span_13](start_span)[span_13](end_span).
3.  스마트폰 바탕화면에 생성된 앱 아이콘을 통해 일반 네이티브 앱처럼 전체 화면으로 쾌적하게 사용할 수 있습니다[span_14](start_span)[span_14](end_span).
